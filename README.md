# 물리 실험 자기평가 루브릭 (Self-Check Rubric)

공학 물리 실험 수업에서 학생이 실험 전후로 자기 이해도를 체크하는 웹앱입니다.

## 주제

- 물리적 아이디어: 메타인지, 실험 오차 분석(통계적 접근)
- 활용 알고리즘: 가중치 기반 점수 산출, 다차원 평가
- 개발 방식: 바이브 코딩 (자연어로 요구사항을 전달해 코드 생성 후 검토·수정)

## 현재 진행 상황 (3일차, 완성)

- [x] 공통 루브릭 6항목 설계 (개념 이해, 실험 설계, 측정·장비, 데이터 처리, 오차 분석, 결론·해석)
- [x] 항목별 4단계(미흡·기초·능숙·우수) 수준 설명
- [x] 실험별 특화 문항 구조 (예시: 자유낙하 실험)
- [x] 학생 흐름: 사전 자기평가 → 측정 결과 입력 → 사후 자기평가 → 결과 분석
- [x] 브라우저 저장(localStorage)
- [x] 측정값 입력과 통계 분석 (평균, 표준편차, 표준오차, 95% 신뢰구간, 오차율)
- [x] 메타인지 분석 (예상 오차율 vs 실제 오차율, 자기평가 vs 실제 정확도)
- [x] 항목별 가중치를 반영한 점수, 레이더 차트, 자동 피드백
- [x] 교수자 대시보드: 응답 분석(항목별 전후 평균, 예상 vs 실제 오차율 산점도, 학생별 결과 표, CSV 내보내기)
- [x] 실험 관리: 공통 6문항은 고정, 실험마다 이론값·허용 오차·특화 문항 추가
- [x] 가중치 설정: 항목별 가중치와 종합 지수 비율 조정
- [x] 서버 저장: Claude 아티팩트 데이터베이스 연동 (학생은 본인 응답만, 교수자는 전체 응답 조회)

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 그래프는 Chart.js(CDN)를 사용하므로 인터넷 연결이 필요합니다.

- 로컬에서 열거나 GitHub Pages로 배포하면 **미리보기 모드**로 동작합니다. 데이터는 그 브라우저에만 저장되고, 학생 화면과 교수자 화면을 모두 볼 수 있습니다.
- Claude 아티팩트로 배포하면 데이터베이스에 저장되어 여러 학생의 응답을 교수자가 모아 볼 수 있습니다.

## 점수 계산 방식

- 자기평가 총점: Σ(가중치 × (단계 − 1) / 3) / Σ가중치 × 100
- 측정 정확도 단계: 오차율이 허용 오차의 40% 이내면 4, 허용 오차 이내면 3, 2배 이내면 2, 그 이상이면 1
- 메타인지 판정: 사후 자기평가(측정·데이터·오차 분석 평균) − 측정 정확도 단계가 +1 이상이면 과대평가, −1 이하면 과소평가, 그 사이면 보정 양호
- 종합 지수: 자기평가 총점 × 비율 + 측정 정확도(100점 환산) × (1 − 비율)
